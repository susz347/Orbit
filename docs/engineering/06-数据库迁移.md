# 数据库迁移

> 改之前用 `CREATE TABLE IF NOT EXISTS` 原生 SQL 建表，Schema 变更无迹可循。改之后引入 Alembic，每次变更都是独立文件，可升级、可回滚。

---

## 改前 vs 改后

**改前**（`multitenant/db.py`）：
```python
def init_db():
    conn = _get_db()
    conn.executescript("""
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            username TEXT UNIQUE NOT NULL,
            ...
        );
        CREATE TABLE IF NOT EXISTS tenants (...);
        CREATE TABLE IF NOT EXISTS sessions (...);
    """)
    conn.commit()
```

问题：
- 加列、改索引、新表时，开发环境手动改了但生产没改
- 回滚无法操作
- 多人协作时 schema 冲突

**改后**（`multitenant/db.py`）：
```python
def init_db():
    alembic_cfg = AlembicConfig(alembic_ini)
    command.upgrade(alembic_cfg, "head")  # 自动执行所有未应用的迁移
```

## 初始迁移文件

```python
# alembic/versions/f7a4c3a193d7_initial_schema.py

revision = 'f7a4c3a193d7'
down_revision = None  # 这是第一条迁移

def upgrade():
    op.execute("""
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            username TEXT UNIQUE NOT NULL,
            password_hash TEXT NOT NULL,
            role TEXT DEFAULT 'user',
            tenant_id TEXT,
            created_at TEXT DEFAULT (datetime('now'))
        )
    """)
    op.execute("CREATE TABLE IF NOT EXISTS tenants (...)")
    op.execute("CREATE TABLE IF NOT EXISTS sessions (...)")

def downgrade():
    op.execute("DROP TABLE IF EXISTS sessions")
    op.execute("DROP TABLE IF EXISTS tenants")
    op.execute("DROP TABLE IF EXISTS users")
```

每条迁移都有 `upgrade()` 和 `downgrade()`，可来回切换。

注意：Agent Loop 表和 Memory 表由各自模块独立管理，不属于 Alembic 的管辖范围——它们有自己的独立 SQLite 文件。

## 执行流程

```python
def init_db():
    os.makedirs(os.path.dirname(DB_PATH) or ".", exist_ok=True)

    if not os.path.exists(DB_PATH):
        sqlite3.connect(DB_PATH).close()  # 创建空文件让 Alembic 可连接

    alembic_ini = ".../alembic.ini"
    alembic_cfg = AlembicConfig(alembic_ini)

    # DATABASE_URL 环境变量覆盖配置文件中的值
    if db_url := os.getenv("DATABASE_URL"):
        alembic_cfg.set_main_option("sqlalchemy.url", db_url)

    command.upgrade(alembic_cfg, "head")
```

首次运行 → Alembic 检测数据库为空 → 执行所有迁移文件。已有数据库 → Alembic 只执行新增的迁移。

## 日常使用

```bash
# 新增迁移（如加列）
cd backend
alembic revision -m "add_user_email"
# 编辑 alembic/versions/xxx_add_user_email.py
# 重启服务 → 自动执行新迁移

# 回滚一条迁移
alembic downgrade -1

# 查看当前版本
alembic current

# 生成的 SQL 预览（不执行）
alembic upgrade head --sql
```
