# 全局异常处理

> 改之前，未捕获异常直接抛 500 HTML 页面给 API 客户端。改之后，统一返回结构化 JSON，隐藏堆栈，提供 `request_id` 用于排查。

---

## 改前 vs 改后

**改前**：FastAPI 默认 handler → HTML 500 页面
```html
<!DOCTYPE html><html><body><h1>500 Internal Server Error</h1>
<p>File "app/generate/service.py", line 58, in generate_answer ...
UnboundLocalError: cannot access local variable 'x'</p></body></html>
```

**改后**：全局 handler → JSON 错误响应
```json
{
    "error": "Internal Server Error",
    "detail": "An unexpected error occurred",
    "request_id": "a1b2c3d4-..."
}
```

---

## 实现

### 核心函数

```python
# backend/app/middleware/error_handler.py

async def global_exception_handler(request: Request, exc: Exception) -> JSONResponse:
    request_id = get_request_id(request)

    # ── 已知异常：HTTPException（401/403/404 等）──
    if isinstance(exc, StarletteHTTPException):
        logger.warning("http_exception", status_code=exc.status_code,
                        detail=str(exc.detail), request_id=request_id, path=request.url.path)
        return JSONResponse(
            status_code=exc.status_code,
            content={"error": str(exc.detail), "request_id": request_id},
        )

    # ── 未知异常：记录完整堆栈 → 返回通用 500 ──
    logger.error("unhandled_exception", exc_info=True,
                  request_id=request_id, path=request.url.path, method=request.method)

    return JSONResponse(
        status_code=500,
        content={
            "error": "Internal Server Error",
            "detail": str(exc) if _is_dev() else "An unexpected error occurred",
            "request_id": request_id,
        },
    )
```

### 注册方式

```python
# backend/app/main.py
app.add_exception_handler(Exception, global_exception_handler)
```

在 CORS 中间件之前注册，确保跨域请求的错误也能正确处理。

---

## 三层处理逻辑

| 异常类型 | 状态码 | 日志级别 | 响应内容 |
|---------|--------|---------|---------|
| HTTPException（已知） | 原始状态码 | WARNING | `{"error": "错误描述", "request_id": "..."}` |
| RateLimitExceeded | 429 | WARNING | slowapi 自带 handler |
| 其他 Exception（未知） | 500 | ERROR + 完整堆栈 | `{"error": "Internal Server Error", "request_id": "..."}` |

### 开发环境 vs 生产环境

```python
def _is_dev() -> bool:
    return os.getenv("ENV", "development").lower() in ("dev", "development", "local")
```

- **开发环境**：`detail` 返回原始异常信息，便于调试
- **生产环境**：`detail` 返回 `"An unexpected error occurred"`，防止信息泄露

---

## 收益

1. **客户端友好**：所有错误都是 JSON，不需要 switch 响应的 Content-Type
2. **安全**：生产环境不泄露堆栈，内部路径和代码结构不被导出
3. **可追踪**：每个错误响应都带 `request_id`，日志里 grep 就能回溯全链路
4. **日志分级**：已知故障记 WARNING，未知故障记 ERROR + exc_info，防止告警风暴覆盖真正的问题
