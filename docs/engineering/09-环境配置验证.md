# 环境配置验证

> 改之前，缺失 API Key 时静默降级，缺失 SECRET_KEY 时自动生成随机值。改之后，启动时强制校验关键配置，缺失则拒绝启动——让问题尽早暴露。

---

## 改前 vs 改后

**改前**：启动不报错，运行到一半才发现问题。
- `LLM_API_KEY` 未设置 → 静默降级为"无 LLM 模式"
- `SECRET_KEY` 未设置 → 自动生成随机值，重启后所有 Token 失效

**改后**：启动时检查，不满足条件直接 `sys.exit(1)`。
- `LLM_API_KEY` 未设置 → ❌ 拒绝启动
- `SECRET_KEY` 长度 < 16 → ❌ 拒绝启动
- `CORS_ORIGINS` 含通配符 `*` → ⚠️ 警告（生产环境安全风险）

---

## 实现

```python
# backend/app/config.py

def _validate_config_on_startup():
    """启动时校验关键配置，缺失或无效则拒绝启动。"""
    errors = []

    # LLM API Key
    llm_api_key = os.getenv("LLM_API_KEY", "").strip()
    if not llm_api_key:
        errors.append("LLM_API_KEY 未设置。请在 .env 文件中配置 LLM_API_KEY。")

    # JWT Secret Key
    jwt_secret = os.getenv("SECRET_KEY", "").strip()
    if len(jwt_secret) < 16:
        errors.append(
            "SECRET_KEY 未设置或长度不足（需 >= 16 字符）。"
            "缺少 SECRET_KEY 会导致每次重启后所有用户 Token 失效。"
        )

    # CORS Origins（生产环境不应使用通配符）
    cors_origins = os.getenv("CORS_ORIGINS", "http://localhost:3000")
    if "*" in cors_origins:
        errors.append("CORS_ORIGINS 不应包含通配符 *（安全风险）。请指定具体域名。")

    # ChromaDB 持久化目录
    persist_dir = settings.rag.storage.persist_dir
    if not os.path.isdir(persist_dir):
        try:
            os.makedirs(persist_dir, exist_ok=True)
        except OSError as e:
            errors.append(f"无法创建 ChromaDB 持久化目录 {persist_dir}: {e}")

    if errors:
        print("=" * 60, file=sys.stderr)
        print(" 配置错误 — 服务拒绝启动", file=sys.stderr)
        print("=" * 60, file=sys.stderr)
        for i, err in enumerate(errors, 1):
            print(f" [{i}] {err}", file=sys.stderr)
        print("=" * 60, file=sys.stderr)
        sys.exit(1)
```

### 在 lifespan 中调用

```python
# backend/app/main.py

@asynccontextmanager
async def lifespan(app: FastAPI):
    setup_logging()

    # 测试环境跳过（conftest.py 设置了 PYTEST_RUNNING=1）
    if not os.getenv("PYTEST_RUNNING"):
        from .config import _validate_config_on_startup
        _validate_config_on_startup()

    ...
```

**`PYTEST_RUNNING` 标记确保了测试不会被生产级校验拦下来**——测试环境有自己的一套配置逻辑。

## 校验项一览

| 校验项 | 条件 | 失败处理 |
|--------|------|---------|
| `LLM_API_KEY` | 必须设置 | ❌ 拒绝启动 |
| `SECRET_KEY` | 长度 >= 16 字符 | ❌ 拒绝启动 |
| `CORS_ORIGINS` | 不能含 `*` | ⚠️ 警告，不阻止启动 |
| ChromaDB 目录 | 可写 | ❌ 拒绝启动（若无法创建） |
