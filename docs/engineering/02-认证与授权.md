# 认证与授权

> 核心理念：**渐进式**——不是"不登录就滚"的高墙，而是从零摩擦体验到完整安全的平滑路径。

---

## 两条路径并存

```
用户请求 ──→ Authorization: Bearer <token>?
                │
        ┌───────┴───────┐
        │ 有 Token       │ 无 Token
        ▼                ▼
 get_current_user()   get_optional_user()
        │                │
 JWT 解析失败 → 401    返回 None
 JWT 解析成功 → user    继续处理（匿名模式）
```

**场景 A**：新用户不注册，也能用知识库搜索、文档上传。

**场景 B**：注册后带 JWT，长期记忆、Agent Loop、会话管理强制鉴权。

## 密码学基础

### bcrypt 哈希

```python
def _hash_password(password: str) -> str:
    password_bytes = password.encode("utf-8")[:72]   # bcrypt 72 字节限制
    return bcrypt.hashpw(password_bytes, bcrypt.gensalt(rounds=12)).decode()

def _verify_password(password: str, stored: str) -> bool:
    return bcrypt.checkpw(password.encode("utf-8"), stored.encode("utf-8"))
```

- **`rounds=12`**：2^12 = 4096 次迭代，暴力破解效率从百万级降到百级
- **`[:72]`**：bcrypt 输入超过 72 字节会被静默截断，显式截断是防御性编程
- **salt 自动内嵌**：`stored` 格式为 `$2b$12$<salt><hash>`，`checkpw` 自动提取 salt

### JWT 签发

```python
ALGORITHM = "HS256"          # 对称签名，单服务足够
ACCESS_TOKEN_EXPIRE_DAYS = 7  # 不短不长的折中

def create_access_token(username, user_id, tenant_id=None):
    payload = {
        "sub": username,       # 标准字段
        "user_id": user_id,    # 自定义字段：数据库主键
        "tenant_id": tenant_id,
        "exp": now + 7 days,   # 到期时间
        "iat": now,            # 签发时间
    }
    return jwt.encode(payload, _SECRET_KEY, algorithm=ALGORITHM)
```

Payload 包含后续授权所需的全部信息——后续 API 解码 Token 就知道"你是谁、属于哪个租户"，不需再查数据库。

### verify_access_token 为什么不用 lru_cache

三个原因：

1. **性能不需要**：HMAC-SHA256 解码是微秒级
2. **过期 Token 续命**：缓存"12:00 通过"的结果，Token 12:01 过期后仍能用
3. **内存泄漏**：缓存的 payload 含敏感信息（username、user_id）

## 两个依赖注入函数

### get_current_user（强制认证）

```python
async def get_current_user(token: str = Depends(oauth2_scheme)) -> dict:
    if not token:
        raise HTTPException(401, "未提供认证 Token")
    payload = verify_access_token(token)
    if not payload:
        raise HTTPException(401, "Token 无效或已过期")
    return {"user_id": ..., "username": ..., "tenant_id": ...}
```

`oauth2_scheme` 设置 `auto_error=False`——Token 缺失时不自动抛异常，而是返回 None，让 get_current_user 自己决定返回什么错误信息。

### get_optional_user（可选认证）

```python
async def get_optional_user(token: str = Depends(oauth2_scheme)) -> Optional[dict]:
    if not token:
        return None
    payload = verify_access_token(token)
    if not payload:
        return None
    return {"user_id": ..., "username": ..., "tenant_id": ...}
```

**三种情况都返回有效值**：没带 Token → None；过期 → None；有效 → 用户信息。

## 授权（Authorization）

认证回答"你是谁"，授权回答"你能做什么"。

### 租户隔离（数据级）

```python
def get_user_collection(user_id: int) -> str:
    return f"user_{user_id}"
```

每个用户的 ChromaDB collection 按 `user_{user_id}` 命名。用户 A 的文档存在 `user_1`，用户 B 检索时查的是 `user_2`。

### Loop 归属校验（操作级）

```python
def _check_loop_access(loop_id, current_user):
    loop = get_loop(loop_id)
    if loop["user_id"] != current_user["user_id"]:
        raise HTTPException(403, "无权操作此 Loop")  # 403 而非 404
```

返回 403 而非 404 是关键——404 会让攻击者区分"这个 loop 不存在"和"这个 loop 存在但不是你的"。

## 防 SQL 注入

```python
conn.execute("SELECT id FROM users WHERE username = ?", (username,))
conn.execute("INSERT INTO users (username, password_hash) VALUES (?, ?)", (...))
conn.execute("INSERT INTO sessions (id, user_id, context) VALUES (?, ?, ?)", (...))
```

## 限流

```python
@router.post("/register")
@limiter.limit("5/minute")
def api_register(...): ...

@router.post("/login")
@limiter.limit("5/minute")
def api_login(...): ...
```

5 次/分钟对正常用户绰绰有余，对暴力破解是有效阻断。
