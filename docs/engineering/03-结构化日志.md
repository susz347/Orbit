# 结构化日志

> 从"纯文本日志"升级到"可查询的结构化日志"，每条日志自动携带 `request_id`，可接入 ELK/Loki/CLS 等集中式日志系统。

---

## 改前 vs 改后

**改前**（纯文本，无法查询）：
```
INFO:app.main:Knowledge Base Service starting...
ERROR:app.generate.service:LLM 调用失败: Timeout
```

**改后**（JSON，可按字段过滤）：
```json
{"event": "knowledge_base_starting", "version": "1.0.0", "timestamp": "2026-08-11T10:00:00Z", "level": "info", "logger": "app.main", "request_id": "a1b2c3d4"}

{"event": "llm_call_failed", "model": "deepseek-v4-pro", "error": "Timeout after 30s", "timestamp": "2026-08-11T10:01:00Z", "level": "error", "logger": "app.generate.service", "request_id": "a1b2c3d4"}
```

排查问题时，用 `request_id=a1b2c3d4` 即可过滤出整条请求链路的所有日志。

## 三层架构

```
┌──────────────────────────────────────┐
│  应用代码                             │
│  logger = get_logger(__name__)       │
│  logger.info("event_name", k=v, ...) │
└──────────────┬───────────────────────┘
               │
┌──────────────▼───────────────────────┐
│  structlog 配置                       │
│  ┌─────────────────────────────┐    │
│  │ 预处理链                      │    │
│  │ add_logger_name              │    │
│  │ add_log_level                │    │
│  │ TimeStamper(iso)             │    │
│  │ format_exc_info              │    │
│  ├─────────────────────────────┤    │
│  │ 输出渲染器                    │    │
│  │ 开发: ConsoleRenderer(彩色)   │    │
│  │ 生产: JSONRenderer()         │    │
│  └─────────────────────────────┘    │
└──────────────┬───────────────────────┘
               │
┌──────────────▼───────────────────────┐
│  标准 logging 桥接                    │
│  root_logger → StreamHandler(stdout) │
│  第三方库日志也走同一管道              │
└──────────────────────────────────────┘
```

## 初始化流程

```python
# backend/app/logging_config.py

def setup_logging():
    is_dev = os.getenv("ENV", "development") in ("dev", "development", "local")

    # 1. 配置标准 logging（第三方库日志也走 stdout）
    _config_stdlib_logging(is_dev)

    # 2. 配置 structlog（应用日志的结构化输出）
    _config_structlog(is_dev)
```

### 标准 logging 配置

```python
def _config_stdlib_logging(is_dev: bool):
    handler = logging.StreamHandler(sys.stdout)
    handler.setFormatter(logging.Formatter(
        "%(message)s" if is_dev else
        '{"logger": "%(name)s", "level": "%(levelname)s", "event": %(message)s}'
    ))
    root_logger = logging.getLogger()
    root_logger.handlers.clear()
    root_logger.addHandler(handler)
    root_logger.setLevel(logging.INFO)
    _silence_noisy_libraries()  # chromadb/httpx/urllib3 → WARNING+
```

### structlog 配置

```python
def _config_structlog(is_dev: bool):
    shared_processors = [
        structlog.stdlib.add_logger_name,
        structlog.stdlib.add_log_level,
        structlog.processors.TimeStamper(fmt="iso"),
        structlog.processors.StackInfoRenderer(),
        structlog.processors.format_exc_info,
    ]

    if is_dev:
        structlog.configure(
            processors=shared_processors + [structlog.dev.ConsoleRenderer(colors=True)],
            ...
        )
    else:
        structlog.configure(
            processors=shared_processors + [structlog.processors.JSONRenderer()],
            ...
        )
```

## request_id 自动注入

`RequestIDMiddleware` 在请求进来时调用 `structlog.contextvars.bind_contextvars(request_id=...)`，此后该请求生命周期内的所有日志自动带 `request_id`：

```python
class RequestIDMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        request_id = request.headers.get("X-Request-ID") or str(uuid.uuid4())
        request.state.request_id = request_id
        structlog.contextvars.bind_contextvars(request_id=request_id)

        try:
            response = await call_next(request)
            response.headers["X-Request-ID"] = request_id
            return response
        finally:
            structlog.contextvars.clear_contextvars()  # 防止污染下一个请求
```

## 噪音控制

以下第三方库的日志级别被下调，避免日志爆炸：

```python
noisy = {
    "chromadb": WARNING,
    "chromadb.telemetry": ERROR,
    "httpx": WARNING,
    "httpcore": WARNING,
    "urllib3": WARNING,
    "sentence_transformers": WARNING,
    "asyncio": WARNING,
    "uvicorn.access": WARNING,
}
```

## 使用方式

```python
from .logging_config import get_logger

logger = get_logger(__name__)

# 基础使用
logger.info("llm_call_completed", model="deepseek-v4", tokens=1523, latency_ms=320)

# 绑定上下文
logger = get_logger(__name__).bind(user_id=42)
logger.info("user_action", action="upload")  # 自动带 user_id
```
